# e66e39e6

This commit reintroduced a large batch of Lumbridge content and expanded the core API.

## Restored plugins
- `BarfyBillPlugin`
- `BartenderPlugin`
- `CookPlugin`
- `CookingTutorPlugin`
- `CraftingTutorPlugin`
- `DoomsayerPlugin`
- `GeePlugin`
- `GoblinCookPlugin`
- `HansPlugin`
- `PrayerTutorPlugin`
- `BobPlugin`
- `ShopKeeperPlugin`
- `AlkharidGate`
- `DoorPlugin`
- updated `ChatSpawnsPlugin` to rely on these new NPC plugins

## API changes
- `QueueTaskExt.doubleItemMessageBox` now accepts item names, not IDs
- `WorldExt` overloads for `openDoor` and `closeDoor` accept RSCM names

These updates restore interactive NPCs, shops and door behaviour removed in earlier clean-ups.
